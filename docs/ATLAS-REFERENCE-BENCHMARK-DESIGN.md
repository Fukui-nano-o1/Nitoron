## 2. 参照値の取得方法（1案）

**開発側による実機1台の多視点写真測量（COLMAP等・無償ソフト・CPUで可）。**
- 撮影：静止状態の実機を30〜80枚（全周＋上方、評価5点と基準点がそれぞれ複数枚に写ること）。
- スケール：機体に貼付するスケールバー（市販メジャー／チェッカーボード）を主とし、
  取説documented寸法（全長1470・全幅615・全高1020mm、クローラ幅110mm・ピッチ60mm）を**独立の尺度検証**に使う
  （多視点写真があるだけでは正解値と扱わない：既知寸法との照合まで行って初めて採用）。
- 点の指定：再構成点群上で§1の定義に従い各点を指定。指定は独立に2回行い差を記録（§4）。
- **未確認事項**：実機の所在・アクセス可否（販売店・実機保有者への連絡はこの設計では行わない）。

## 3. 座標系と姿勢合わせ

- 参照座標系：原点＝機体外形包絡の底面中心（接地面上）。+X＝前（取説の機体説明方向の進行方向）、
  +Y＝鉛直上、+Z＝進行方向を向いて左。単位mm。右手系。
- 既存モデル座標系（assemble.mjs規約）：単位m、X=前後（テンプレートはロータリ側+X）、Y=接地0の上方向、
  Z=左右対称中心0。**モデルの左右符号の割り当ては仮定**であり、参照側の定義に合わせて評価で検証される。
- 変換：**評価5点とは別の整合基準点≥3点**で相似変換（スケール＋回転＋並進、Umeyama法、反転禁止 det(R)=+1）
  を推定。基準点候補（固定・定義容易）：クローラ駆動スプロケット軸の左右端中心／前部転輪軸中心／ハンドル左右グリップ端
  （ハンドルは3段調節のため**中段・正位置を事前固定**）。変換の残差は基準点についてのみ別掲し、
  評価5点への合わせ込み残差を予測精度として報告しない（仕様§4どおり）。

## 4. 測定誤差の確認方法

1. 同一点の独立2回指定の差（点指定の再現性）
2. documented寸法との照合誤差（全長・全幅・全高・クローラ幅110mm/ピッチ60mm・再構成スケールの整合）
3. 基準点の変換残差（姿勢合わせ品質）
4. 写真測量の再投影RMSE（再構成品質）
- 目標：測定誤差合計が、想定される予測誤差（数百mmオーダー）より十分小さいこと（±10〜20mm級を見込み。
  **見積りであり未実測**）。不明値は不明のまま保存。推定モデル由来の座標を正解に流用しない。

## 5. 評価値（仕様§4の確認）

5点それぞれの3D距離誤差(mm)・中央値・最大値・部品対応の成否・観測できた数／予定数。2D誤差は別欄。
観測不能は欠測のまま。事後の点の交換をしない。
許容誤差のmm値は候補結果を見る前に根拠つきで設定する（現時点では未設定・未確認）。
参照セット完成や誤差測定だけで工程A達成とはしない。

## 7. 採点コードの差分要件（Codex向け・今回は実装しない）

- 入力：`reference.json`（座標系宣言／評価5点(mm)／整合基準点≥3点(mm)／誤差見積り／出典・測定メタ）
  ＋既存ジョブの`machine.json`・実験出力（予測座標・部品ID）
- 処理：基準点のみでUmeyama相似変換（反転禁止）→基準点残差を別掲→5点の3D距離誤差(mm)・中央値・
  最大・対応成否・観測数／予定数。2D誤差別欄。欠測は欠測のまま
- 強制事項：基準点と評価点のID重複を拒否（評価点フィット禁止をコードで強制）。参照値は読み取り専用。
  決定的（乱数なし）。documented3dPartsの昇格なし（実寸受入は事前固定の許容mm設定後の別判定）
- 出力：`benchmark.json`＋表ビューア。同一入力3回のSHA一致
