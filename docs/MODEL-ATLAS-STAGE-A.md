## 実装した共通処理（scripts/atlas/）

- `registry.mjs` 機種台帳・表記正規化（型式末尾を落とさない）・特定（推測で確定しない）
- `net.mjs` 出所記録つき取得。公開HTTPSのみ・リダイレクトのホスト検査・回数/ページ/時間予算・
  egress遮断を `network-blocked` として資料不足と区別
- `collect.mjs` メーカールートからの探索（本文に対象型式を含むページだけ資料に採用）
- `extract.mjs` 規則ベース抽出：主要諸元（全長・全幅・全高・質量）と「各部の名称」。資料にない値を補完しない
- `assemble.mjs` カテゴリ別テンプレートを実寸法でパラメータ化した宣言データ（全ノード `positional:'approx'`。
  位置不明部品はメッシュなし・資料案内。分解順序・締付値を主張しない）
- `glb.mjs` 宣言データ→GLB（vendorの既存Three r180・GLTFExporterを使用。新規Three依存なし。任意コード生成なし）
- `verify.mjs` 根拠100%・メッシュ実在・当て推量メッシュ0・寸法妥当性・階層整合の機械照合
- `run.mjs` ジョブ記録（段階別時間・費用・介入・全出所）を `atlas-out/<jobId>/` へ保存
- `tests/atlas-pipeline.test.js` 4件（全体スイート93件に組込み）

## 続行に必要な接続・設定・費用（具体化）

1. **ネットワーク許可（費用0・ユーザー操作）**：この環境の network egress settings に
   取得先ドメインを追加する（初回対象案：`www.honda.co.jp` / `agriculture.kubota.co.jp` /
   `www.yanmar.com`。または開放ポリシーの環境で実行）。許可後に同じコマンドを再実行すれば
   実データ実証を再開できる（コード変更不要）。
2. **構造抽出のAI利用（任意・要予算承認）**：現在の規則ベース抽出で「外観の概略3D＋
   仕様表由来の根拠」までは到達可能。部品図・分解図PDFからの部品階層抽出まで進める場合は
   バックエンドからのClaude API呼出しが必要。一次API価格（2026-06時点の公表値）：
   Claude Sonnet 5 入力$2/出力$10 per 1Mトークン、Claude Opus 5 入力$5/出力$25。
   資料50〜200Kトークン/機種の想定で1機種あたり概ね$0.1〜1のオーダー（実測前の概算。
   実測はキー投入後に取得ログで示す）。APIキーはサーバー側にのみ置く。
3. **写真→3D生成（後段・要GPU）**：TRELLIS.2 / PartCrafter はGPU必須。ホスト型GPUの
   料金は本環境から確認できないため単価を記載しない（作り話の単価を置かない）。
   資料経路の成立を先に確認する。
4. **M9（チャット外実行基盤）**：API受付＋ジョブ管理（例：Supabase）と生成実行環境の
   本番適用が必要。本番DB・ホスティング変更は許可外のため未実施。必要になった時点で
   マイグレーション・関数・戻し方を用意して個別確認にかける。
