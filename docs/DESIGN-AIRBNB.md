# Nitoron デザイン更新・第2段階

2026-09-08更新。第1段階は9428a92で利用者がプッシュ済み。この差分は追加更新です。

白い背景、黒い本文、コーラルのアクセント、大きな丸い検索欄、横並びの分類、写真中心の一覧を採用。カードのハートで保存し、写真を切り替え、詳細で写真・発表者・条件・本文・対話へ進めます。詳細の右側には挑戦・学習・比較の操作をまとめ、スマホでは下部へ配置します。

画面部品：SiteHeader、Catalog、Cover、FilterDialog、PhotoGallery、PublicRecord、Icon、design.css。添付・保存・返信は画面だけの装飾ではなく、Supabaseとの保存処理と権限制御を実装しています。

Airbnbを参考にした実装です。ロゴ・文章・掲載写真は転用していません。実ブラウザでの照合は行っておらず、ピクセル単位で完全一致したとは主張しません。

第2段階の機能、SQL、検証、未完了事項はSTAGE2-DELIVERY.mdを参照。旧Nitoron-Design-Preview.htmlは第1段階の参考画面です。

追加更新（記録編集ページ）：Airbnbの掲載編集画面を参考に、編集画面を丸角カード・角丸の戻るボタン・固定ツールバー・保存状態チップへ更新。あわせて、新規作成は最初の入力があるまで保存しない仕様に変更し（空の経営発表が並ぶ問題の修正）、既存の空記録は「自分の記録」の「空の記録を整理」から一括削除できます。

追加更新（カードの三本線メニュー）：Airbnbの保存・操作シートを参考に、公開カードのハート横へ三本線ボタンを設置。タップでモーダルを開き、保存リストの追加・外し、自分だけのメモ（`nitoron_card_memos`、本人のみ読める）、発表ページの対話欄への移動（質問・指摘）、発表者のフォロー（`nitoron_follows`、本人のみ読める）と発表者ページへの移動をまとめました。SQLは `20260908153322_nitoron_follows_and_card_memos.sql`（適用済み）、RLSの検証は `tests/database-follows-memos.test.js`。

追加更新（発表閲覧ページ、2026-09-09）：Airbnbの物件詳細ページを参考に、発表者セクションを「◯◯さんの経営発表」表記へ変更し、概要の下へアイコン付きハイライト行（観測した事実の件数・経営の数字の有無・写真と資料の点数・対話のしかた）を追加。スマホでは、これまで非表示になっていた比較操作を、Airbnbの予約バーにあたる下部固定バー（保存と比較への追加）として表示します。
