# Nitoron デザイン更新

作成日・確認日：2026-09-07

## 変更

- 左の固定サイドバーを、上部ナビゲーションとスマートフォンの下部ナビゲーションへ変更。
- 大きな丸い検索欄を中心に、作物・本文の全文検索と地域検索を配置。
- 一覧を写真中心のカードへ変更。写真、種類、地域・作物、タイトル、要約、発表者、記録した数値の順に表示。
- 「比較 ＋」から最大3件を選択できる。架空の評価点や人気順位は表示しない。
- カバー写真URLを既存の構造化メタデータに追加。写真がない場合・読み込めない場合も、作物名を使う表紙で表示する。
- 読む画面にカバーを配置し、概要・条件・観測・仮説・結果の読み順を整理。
- 白、黒、赤を基調に、余白、角丸、フォーム、ダイアログ、公開確認画面を統一。

## ファイル

- 新規：`src/SiteHeader.jsx`、`src/Catalog.jsx`、`src/Cover.jsx`、`src/design.css`、この文書。
- 変更：`src/main.jsx`、`src/domain.js`、`src/community.js`、`src/Editor.jsx`、`src/RecordBody.jsx`。
- Stage1の保存・公開・指摘・比較機能とSQLを引き継ぐ。
- 依存パッケージの追加・更新は、このデザイン変更では行っていない。

## 検証

- 自動テスト21件成功。
- フロントエンドの本番ビルド成功。
- プレビューは同じ画面部品を用いてHTML化し、初期描画をサーバー側でも確認した。

## プレビューと本番データ

配布した `Nitoron-Design-Preview.html` は、デザインを確認するための独立した画面。6件の発表と数値は架空。写真は参考素材で、発表の地域・実績写真ではない。検索・詳細・比較・入力を画面内で試せるが、入力は再読み込みで戻る。認証・DB・公開APIへ接続しない。本番アプリにはサンプル記録を追加しない。

本番では登録した記録を表示する。カバーが未入力なら写真なしの表紙になる。写真の直接アップロードは引き続き未実装で、現段階はURLによる指定。

## 本番への残作業

Stage1の `docs/DELIVERY.md` にあるSQL・Authの確認が残る。コードをプッシュしただけで、公開・指摘機能が利用可能になったと判断しない。このデザイン更新による追加のDBマイグレーションはない。
