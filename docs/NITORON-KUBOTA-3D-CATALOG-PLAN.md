## 2. 「クボタアカウントから掲載」について

**クボタ名義のアカウントでの掲載はしない。** クボタの許諾がない状態で「クボタ」を名乗る掲載は、なりすましに当たり、Nitoron の信用を最初の10件で失う。カタログ文言・画像・取説図の転載も許諾未確認（資料パックの注記どおり）。

代わりに：
- 掲載主体は Nitoron の「メーカー別コレクション：クボタ（非公式・参考モデル）」。公式資料は URL で参照し、原文・原図は転載しない。
- 3Dは「公式諸元と公式写真を参照した参考モデル。実寸・適合の証明ではない」の表示を必ず残す（説明ボックスではなく1行の常時表示）。
- クボタ名義で出したいなら、それは提携の話。10機種の参考モデルを持って行けば交渉の材料になる。名乗ってから頼むのではなく、作ってから頼む。

## 3. 「説明ボックスはすべて撤回」について

撤回してよいもの：初回案内（3枚）、使い方ボタン、各画面の説明段落、案内ダイアログの補足文。カタログ3D画面はモデル名・3D・部品名だけでよい。
撤回してはいけないもの：①「参考モデル・実寸未確認」の1行、②修理案内の停止・冷却・原典確認の条件（これを消すと安全性の軸が0になる）、③未対応機種・未知の版の明示。
つまり「説明を消す」のではなく「説明を1行に圧縮し、安全条件は操作の前提として残す」。

## 4. 費用の現実

現状、1機種の3D化は人手作業で、その時間は未計測（作業内訳メモ参照）。10機種を今の方式でやれば、その10倍かかる。
順番を変える：**#1 は既存。#4→#5 の1組だけ先にやり、雛形から数値入力で2機種目が何時間で出るかを計る。** それが出るまで残り8機種に手を付けない。数字が「数時間」なら10機種は現実的、「数日」なら雛形の設計をやり直す。
