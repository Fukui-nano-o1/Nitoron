2026-09-16。クボタ公式の白ねぎ栽培ガイドとTAシリーズの製品ページを確認し、15カード（型式・品番26件）を追加。

- クボタ製品2件：KV2200、DR-3UD。
- クボタ掲載アタッチメント5件：植付け溝・埋め戻し・土揚げ・掘取り。製造元がページに明記されないものは「クボタ取扱」と表示し、品番を型式と区別。

- 既存のFTN800・TA801N・JB13XNは重複登録しない。一般名称だけの機器や型式・メーカー対応が不明な項目は未登録。全機種網羅の判定ではない。

各JSONに短い概要・確認した型式／品番・公式参照先を保存。写真は15件とも確認し、装着例はその旨を表示。未確認の修理手順・症状・3D参照は追加しない。
