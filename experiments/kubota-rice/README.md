トラクタは公式分類全体を補完。野菜向けの乗用管理機やローダ専用機も含み、全機が水稲専用という意味ではない。収穫機は麦・大豆・そば用に分類された3製品を対象外とした。過去の全製品や全オプション仕様、別分類のトラクタ作業機まで網羅した件数ではない。

各カードは製品写真、短い概要、公式掲載の型式、製品・資料リンクを持つ。写真はシリーズの公式掲載例で、全仕様共通の外観とは扱わない。カタログ・取扱説明書の本文は今回レビューしておらず、修理手順や3Dは追加していない。

ライスセンター・育苗施設・複合施設の3件は個別構成の施設として保存する。型式を創作せず、`modelPolicy: project-specific` と構成文を必須とする。公式ページにカタログがない場合は確認日付きの `not-listed` とし、存在しない資料リンクを生成しない。発売予定・在庫限り・受注生産の情報を保持する。

写真は公式URL参照で、配信ディレクトリへの画像・PDFの複製はない。写真の許諾を取得したという意味ではない。認証・メール・RLS・Chitose-bankの設定は変更していない。

確認：`node experiments/kubota-rice/check-data.mjs`、関連テスト9件、`npm run build`。画像65件を取得・描画して対応を確認し、DBの65件を生成内容と比較。既存行は更新前後のハッシュで同一を確認。今回の実ブラウザ操作・実機修理の検証は実施していない。

`coverage.json` が追加対象、`source-checks.json` が取得元とSHA、`photo-checks.json` が写真の取得結果、`record-checks.json` と `database-checks.json` が確認結果。
