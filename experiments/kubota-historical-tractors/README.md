# クボタ旧型トラクタ10型式の追加

確認日：2026-09-16。現行製品群・特殊仕様の42カードに、未掲載の旧型10型式を追加した。掲載データへの反映を確認済みで、トラクタ分類は52カード。

対象：GL23、GL32、KL21、KL27、KL33、KT24、GB14、GT21、FT25、MZ65。

公式の取扱説明書検索（基本型式の完全一致）で型式・馬力・取説の案内先を確認し、公式販売年度検索で販売期間を照合した。GL32とGL320、KL21とKL210などを区別する。FT25の販売年度は公式表記のFT25(F)を明記する。

旧型用の `historical-overview` として、製品概要・対象型式・公式資料の参照先を通常のカード形式へ変換する。確認日の付いた出典を各カードに3件添える。取説本文は未精読。写真は型式の一致を確認できていないため、他機種の写真を流用せず未登録とする。修理手順・3Dは含めない。

IDは既存と同じメーカー・基本型式から決定する。掲載直前にID・型式の重複を再確認し、10件の記録と掲載スナップショットを一括挿入した。保存内容の完全一致と既存行のハッシュ不変をトランザクション内で検証済み。既存IDへの上書きはしない。

再生成：`node scripts/catalog-to-record.mjs data/catalog/kubota/<型式の小文字>.json`

検証：`node experiments/kubota-historical-tractors/check-records.mjs`、既存カタログ関連テスト、`npm run build`。掲載件数と保存内容は `database-check.json` を参照。
