# 外装を一度定義し、寸法違いを保存して交換する

2026-09-11 / Codex実装候補。PC752N寸法ボックスと共通部品庫を接続した独立試作。

`PC752N-exterior-viewer.html` をブラウザで開く。外部実行依存なし。版を選び「この形状に交換」、または「カバーの箱へ」。開発用欄で長さ・幅・高さ・中央のふくらみを変え、別版保存後に交換する。

## 実行

```sh
npm test
npm run build
npm run check:browser
```

Playwrightまたはplaywright-coreを使用。必要なら `ATLAS_CHROMIUM_PATH` と `NODE_PATH` に既存環境を指定。Codex検証はChromium 152 / SwiftShader。実機iPhoneは未確認。ファイル直接表示でのlocalStorageはブラウザ依存。JSONでも受け渡せる。

## 構造

- `arched-loft.mjs`: アーチ断面列をつなぐ共通曲面。X=長さ/Y=高さ/Z=幅。板厚・穴・中空構造は生成しない。
- `catalog.mjs`, `geometry.mjs`: 既存5分類を維持して `archedLoft / arched-loft-v1` を追加。版は不変。同じ形状はGeometryPoolで共有。
- `cowling-recipes.mjs`: 既存PC752N上部カバーから一度転記した断面列。実資料から新たに自動抽出したものではない。
- `cowling-bridge.mjs`: 既存単一メッシュ形式への変換。部品ID・基点形状・取付座標を照合し、原点 `[-663,601,0] mm` を加える。自動フィット・取付先の推測なし。
- `model.mjs`: 上部カバーだけを共通生成に置換。旧版は `baseline/model.mjs`。それ以外の外観は従来どおり。
- `assembly.mjs`, `presentation.mjs`, `part-package.mjs`: 既存コードを無変更で再利用。ID・取付姿勢・分解ベクトル・表示手順を維持。
- `exterior-ui.mjs`: 開発用の寸法違い保存・交換・JSON受け渡し。一般利用者にこの作業を要求しない。

GeometryPoolで2配置が同じ形状を参照し生成1回を確認。既存交換形式へはフレーム変換した数値配列をコピーするため、機械表示まで含めた全バッファ共有とは主張しない。InstancedMesh未使用。FPS・人手工数削減は未実測。

## 保存範囲

保存キー `nitoron:exterior-library:v1`。全レシピと部品庫から適用した版を保存。以前の部品庫キーは書き換えない。JSONは既存版と衝突しないものをマージし、明示したbindingのみ適用。binding=nullは配置を変更しない。カメラ・分解・透過は同じ画面での交換時に維持し、再読込では初期表示へ戻る。

従来の形状JSON入口からの更新はこの保存に含めない。取り消しで前の部品庫版に戻った場合はその版を追跡する。不正入力・版衝突・取付先違い・全体外寸を変える配置は拒否。保存失敗は明示しJSONを書き出せる。

## 測定結果

174メッシュの頂点・面・法線・姿勢は元と完全一致。カウリング126頂点、モデル寸法324×288×107mm。別版例は340×270×125mm、中央のふくらみ1.1。全体箱1470×615×1020mmを維持。

共通生成1種類で既存の上部・下部・操作部の3曲面を再現できることを単体確認。画面・保存・交換は上部カバー1箇所のみ。単体33件、ブラウザ新規14+既存26=40項目。詳細は `evidence/verification.json`。

## 未確認と範囲外

別機種の再利用率、人手工数削減、型番だけの自動生成、部品実寸、規格適合は確認できません。`documented3dParts=0`。アーチ断面以外の任意形状や複数メッシュ部品の交換は未対応。曲面のSVG模式図は未対応（断面値はJSON保存）。Nitoron本体・共有WebGLホスト・クラウドへの接続は行っていない。
