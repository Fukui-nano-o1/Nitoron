# クボタ KT シリーズの基本15型式

公式資料の確認日：2026-09-17。

KTシリーズを基本型式ごとに1カードへまとめる。対象は下表の15型式で、既存4カードの資料を補完し、未掲載11型式を追加する。仕様違いの販売期間・取扱説明書・補足資料は該当する基本型式のカードに掲載し、資料数をカード数として数えない。

| 公式販売年度 | 基本型式 | 今回の扱い |
| --- | --- | --- |
| 2002〜2005年 | KT20、KT22、KT24、KT27 | 既存4カードを更新 |
| 2002〜2005年 | KT30 | 新規1カード |
| 2005〜2008年 | KT210、KT230、KT250、KT280、KT300 | 新規5カード |
| 2008〜2012年 | KT215、KT235、KT255、KT285、KT305 | 新規5カード |

## 網羅する範囲

公式取扱説明書検索の `KT` 接頭検索を全3ページ取得した。検索結果62行のうちトラクタは59行で、基本型式15件、仕様別資料27件、ポイントシート・メンテナンスシート17件に分かれる。トラクタ以外の3行は対象に含めない。各カードには基本型式の取説1件と、対応する関連資料を合わせて掲載する。関連資料は全体で44件、基本取説との合計は59件となる。59件の案内ページはHTTP 200と取得内容のSHA256を確認済み。

公式販売年度検索は全2ページ・34行を確認し、同内容の重複8行を除いた26行を保持する。内訳は基本型式15行と仕様違い11行。三桁型式の `KT280(F)` など、公式の括弧付き表記を保存する。

型式の文字列前方一致だけで資料を割り当てない。KT30とKT300・KT305を別の基本型式として照合する。KT24-FHNなどの資料に基本型式と異なる馬力表記があっても、その値を基本KT24の諸元へ流用しない。補足資料も独立した機械として扱わない。

この網羅性は、確認日に公式検索へ掲載されているKT基本15型式と対応資料に対するもの。公式販売年度検索は過去の全製品の収録を保証していないため、未掲載の歴史的仕様まで網羅したという意味ではない。取説本文の整備手順・部品適合の検証や、PDF本体・ページ画像の再配布は含まない。

## 写真

基本15カードすべてに、掲載元で型式名を照合した中古実機写真を対応付ける。写真の掲載元・画像URL・取得結果・寸法・SHA256は `photo-checks.json`、カードへの対応と重複検査は `coverage-check.json` で確認する。装備・塗装・状態は撮影個体のものであり、新品時の標準仕様や現在の販売在庫を示すものではない。

KT280カードの写真は掲載元の `KT280F` 表記を保持し、公式販売年度検索の `KT280(F)` と照合する。写真登録の基本型式は `KT280`、表示型式は `labelModel: "KT280F"` とし、カードの「写真について」にもKT280Fを明記する。写真の型式を基本型式へ書き換えて仕様差を隠さない。

## 証跡と実行結果

- `index-pages.json`：公式接頭検索の全ページ、結果行、確認日、取得内容のSHA256。
- `source-checks.json`：基本15型式の完全一致取説検索、販売年度、基本取説の案内先。
- `related-documents.json`：公式取説59件の基本型式への対応、資料種別、案内先、HTTP結果・SHA256。販売年度26行と重複行数も保持する。
- `photo-checks.json`：写真15件の掲載元・画像取得と型式照合の記録。
- `coverage-check.json`：生成カードと公式調査結果の一致、基本型式・資料の欠落、写真重複などの検査結果。
- `browser-check.json`：ブラウザ上でのカード・写真表示の確認結果。
- `database-check.json`：掲載データの更新・追加件数、保存内容の一致、重複と対象外の既存データの検査結果。

このREADMEは対象と検証方法を記録する。写真・ブラウザ・データベースへの反映は各レポートの結果を根拠とし、未生成のレポートがある段階では、その工程を完了扱いにしない。mainへの反映はGitのコミット履歴とリモート参照で確認する。

## 再生成と検証

リポジトリのルートで実行する。以下はローカルのカード生成・検査であり、データベース更新やmainへのpushは行わない。

```bash
for model in kt20 kt22 kt24 kt27 kt30 kt210 kt230 kt250 kt280 kt300 kt215 kt235 kt255 kt285 kt305; do
  node scripts/catalog-to-record.mjs "data/catalog/kubota/${model}.json"
done

node experiments/kubota-kt-series/check-series.mjs
node --test tests/catalog-data.test.js tests/catalog-domain.test.js
npm run build
```

`check-series.mjs` は公式調査のmanifestと写真確認の `photo-checks.json` を入力として使い、検査が成功した場合に `coverage-check.json` を出力する。写真の再取得、実ブラウザ表示、データベース反映の成否は別工程として各レポートを参照する。
