## 保存

- 追記操作前に閉じると、既存記録は変更されません。
- 追記プレビューと同意後、既存 `action` / `result` へ追記し `sources` に3ページの根拠を追加します。同じページと同じ追記は重複させません。
- `inputMode='sections'` への変更を画面で明示し「内容・資料」を表示します。自由本文の `blocks` は変更せず、既存 RecordBody/Editor の補足として残ります。
- 既存 `machineRef` を標準では保持し、別チェックで本人が希望した場合だけエアクリーナを対象にします。途中で対象が変わったら転記を停止します。
- `stage` / `verdict` / `observations` は変更しません。公開・本番DB・モデル形状・モデル版も変更しません。
- 現行 `onChange` が保存未確認の `null` を返した場合、案を閉じず案内を出します。この場合、現行保存APIの仕様によりメモリ上には追記済みの場合があります。実際の保存状態は既存SaveChipが根拠です。
